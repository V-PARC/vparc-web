V-PARC 시험 화면

실제 촬영 화면 그대로 반납을 해 보고, 휴대폰 분류기와 서버 판정기가 어떤 확률로 어떻게 판정했는지 결과 화면에서 바로 봅니다. 기록은 시험 세션으로 분리되어 실제 집계에서 빠집니다.

세션 형식은 P00-A-1처럼 P+두 자리, A/B, 숫자 한 자리입니다. 개발 시험은 P00, 사용자 시험 참가자는 P01부터 쓰세요. 누를 때마다 새 반납으로 시작합니다.

이 기기의 시험 기록

여기 목록은 이 휴대폰에만 저장된 사본(최근 30건)입니다. 서버에는 같은 내용이 /data/logs/judge_debug.jsonl에 한 줄씩 남고(위치 좌표 제외), 판정 기록은 DB와 관리자 API(/v1/admin/records?test_session=P00)에서 볼 수 있습니다.
